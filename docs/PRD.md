# 运动队签到考勤系统产品需求文档

## 1. 项目简介

运动队签到考勤系统是一个用于校运动队日常训练签到考勤的管理工具。系统包含管理员后台 Web 和 Flutter 安卓 App，帮助教练、队伍经理、队长快速管理队员信息、创建训练签到任务、现场完成签到，并在训练结束后统计迟到和缺勤情况。

第一版以简单、稳定、可落地为目标，优先解决日常训练中“人员多、分组多、纸质记录麻烦、迟到缺勤统计困难”的问题。

## 2. 用户角色

### 管理员

管理员包括队伍经理、教练、队长等负责训练组织和考勤管理的人。

主要职责：
- 维护队员信息
- 管理训练分组
- 导入成员名单
- 创建签到任务
- 查看签到结果
- 导出考勤数据

### 签到端使用者

签到端使用者包括现场负责签到的人或队员本人。

主要职责：
- 查看当前正在进行的签到任务
- 查看需要签到的成员列表
- 点击成员完成签到
- 查看成员签到状态

## 3. 第一版 MVP 范围

第一版必须包含以下功能：

- 成员管理
- 成员分组
- Excel 导入成员
- 创建签到任务
- 按分组选择签到人员
- 设置规定签到时间
- 设置签到结束时间
- 安卓端展示当前签到
- 安卓端展示成员列表和签到状态
- 点击成员完成签到
- 自动判断正常 / 迟到
- 迟到显示迟到分钟数并标红
- 结束签到后未签到人员标记为缺勤
- 后台查看签到详情
- 导出 Excel

## 4. 暂不包含功能

第一版暂不包含以下功能：

- 人脸识别
- GPS 定位
- 二维码签到
- 微信登录
- 消息推送
- 多学校多队伍
- 复杂权限系统

这些功能可以在第一版稳定后，根据实际使用反馈再评估是否进入后续版本。

## 5. 核心业务流程

### 管理员导入成员流程

1. 管理员进入成员管理页面。
2. 管理员点击 Excel 导入。
3. 系统读取 Excel 中的成员姓名、学号、性别、手机号、分组等信息。
4. 系统校验必填字段和重复数据。
5. 管理员确认导入。
6. 系统创建或更新成员信息，并关联成员分组。

### 管理员创建签到流程

1. 管理员进入创建签到页面。
2. 管理员填写签到标题。
3. 管理员选择参与签到的分组或成员。
4. 管理员设置规定签到时间。
5. 管理员设置签到结束时间。
6. 管理员提交创建。
7. 系统创建签到任务，并为所选成员生成待签到记录。

### 安卓端签到流程

1. 签到端使用者打开安卓 App。
2. App 展示当前正在进行的签到任务。
3. 使用者进入成员签到列表。
4. 使用者点击某个成员。
5. 系统弹出签到确认。
6. 使用者确认后，系统记录签到时间。
7. 系统根据签到时间自动判断正常或迟到。
8. 安卓端即时更新成员签到状态。

### 管理员结束签到流程

1. 管理员进入签到详情页面。
2. 管理员查看当前签到进度。
3. 管理员点击结束签到。
4. 系统将仍为未签到的成员标记为缺勤。
5. 系统将签到任务状态更新为已关闭。
6. 后台展示最终考勤结果。

### 数据导出流程

1. 管理员进入签到详情或数据导出页面。
2. 管理员选择要导出的签到任务。
3. 系统生成 Excel 文件。
4. Excel 中包含成员信息、分组、签到状态、签到时间、迟到分钟数等字段。
5. 管理员下载 Excel 文件。

## 6. 签到状态规则

签到状态包括：

- `pending`：未签到
- `normal`：正常
- `late`：迟到
- `absent`：缺勤

判断规则：

- 当前时间 <= `required_time`：正常
- `required_time` < 当前时间 <= `end_time`：迟到
- 当前时间 > `end_time` 且未签到：缺勤
- 当前时间 > `end_time`：不允许继续签到

迟到分钟数规则：

- 当状态为 `late` 时，迟到分钟数为当前签到时间与规定签到时间之间的分钟差。
- 迟到分钟数不能小于 0。
- 迟到状态在界面中需要标红展示。

## 7. 管理员后台页面

### 登录页

用于管理员登录后台系统。

### 数据看板

展示成员数量、签到任务数量、近期迟到人数、近期缺勤人数等概览数据。

### 成员管理

用于新增、编辑、停用、查看成员信息。

### Excel 导入

用于批量导入成员名单，并展示导入结果和错误提示。

### 签到任务列表

用于查看历史和当前签到任务，支持按状态、时间筛选。

### 创建签到

用于创建新的签到任务，选择分组和成员，设置规定签到时间和结束时间。

### 签到详情

用于查看某次签到的成员状态、签到时间、迟到分钟数和缺勤情况。

### 数据导出

用于导出签到结果 Excel。

## 8. 安卓 App 页面

### 启动页

展示应用启动状态，并进入当前签到页。

### 当前签到页

展示当前正在进行的签到任务，包括标题、规定签到时间、结束时间和当前状态。

### 成员签到列表页

展示本次签到的成员列表、分组、签到状态和迟到分钟数。

### 签到确认弹窗

点击成员后弹出确认弹窗，避免误点签到。

### 签到结果提示

签到完成后展示结果，例如正常签到、迟到签到或签到失败。

## 9. 数据字段说明

### groups

用于存储运动队分组信息，例如短跑组、长跑组、跳远组。

主要字段：
- `id`：分组 ID
- `name`：分组名称
- `description`：分组描述
- `created_at`：创建时间

### members

用于存储队员信息。

主要字段：
- `id`：成员 ID
- `name`：成员姓名
- `student_id`：学号
- `gender`：性别
- `phone`：手机号
- `group_id`：所属分组 ID
- `is_active`：是否启用
- `created_at`：创建时间

### attendance_sessions

用于存储签到任务。

主要字段：
- `id`：签到任务 ID
- `title`：签到标题
- `required_time`：规定签到时间
- `end_time`：签到结束时间
- `status`：签到任务状态，包含 `active` 和 `closed`
- `created_by`：创建人 ID
- `created_at`：创建时间

### session_members

用于存储某次签到中每个成员的签到状态。

主要字段：
- `id`：签到成员记录 ID
- `session_id`：签到任务 ID
- `member_id`：成员 ID
- `status`：签到状态，包含 `pending`、`normal`、`late`、`absent`
- `checkin_time`：实际签到时间
- `late_minutes`：迟到分钟数
- `created_at`：创建时间

## 10. UI 风格

整体风格关键词：

- 年轻
- 运动
- 现代
- 清爽

颜色规范：

- 主色：`#1E40AF`
- 辅助色：`#F97316`
- 成功色：`#22C55E`
- 错误色：`#EF4444`
- 背景色：`#F8FAFC`

界面设计要求：

- 使用圆角卡片承载核心信息。
- 使用状态标签区分未签到、正常、迟到、缺勤。
- 迟到和缺勤状态需要有明显视觉提示。
- 后台界面以清晰、高效、易扫描为主。
- 安卓端界面要适合现场快速操作，按钮和成员列表需要足够醒目。

## 11. 验收标准

第一版完成后，满足以下条件即可判断项目可用：

- 能导入成员
- 能创建签到
- 能选择人员
- 能在安卓端签到
- 能判断迟到
- 能结束签到并标记缺勤
- 能导出 Excel
- 安卓真机可安装运行
