# QA Checklist

本清单用于运动队签到考勤系统的本地开发和测试验收。

## Supabase RLS 检查

- [ ] `database/schema.sql` 已执行，四张核心表已创建。
- [ ] `database/dev_rls_policies.sql` 已执行。
- [ ] `anon` 角色可以满足普通签到端读取当前签到和提交签到。
- [ ] `authenticated` 角色可以满足管理员端读取和管理数据。
- [ ] App 管理员登录后可以读取成员、分组、签到任务和数据看板。
- [ ] Web 后台新增成员或分组后，App 刷新可以看到。
- [ ] App 新增成员或分组后，Web 后台刷新可以看到。
- [ ] 上线前已将开发阶段宽松 RLS 策略收紧。

## Web 后台检查

- [ ] 成员管理列表、新增、编辑、删除正常。
- [ ] 分组管理列表、新增、编辑、删除正常。
- [ ] Excel 导入成员正常。
- [ ] 创建签到正常。
- [ ] 签到任务列表正常。
- [ ] 签到详情正常。
- [ ] 结束签到会将未签到成员标记为缺勤。
- [ ] 导出 Excel 正常。

## Flutter App 普通签到端检查

- [ ] 当前签到页可以读取 active 签到。
- [ ] 无 active 签到时可以进入管理员系统。
- [ ] 成员签到列表可以读取 session_members。
- [ ] 成员按拼音 A-Z 排序。
- [ ] 搜索和状态筛选正常。
- [ ] pending 成员可以签到。
- [ ] 正常签到显示 normal / 正常。
- [ ] 迟到签到显示 late / 迟到和迟到分钟数。
- [ ] 超过结束时间不允许继续签到。
- [ ] 过期签到会将 pending 标记为 absent / 缺勤。
- [ ] 安卓返回键正常。
- [ ] 横屏无明显 overflow。

## Flutter App 管理员端检查

- [ ] 管理员入口可用。
- [ ] Supabase Auth 登录可用。
- [ ] 管理员首页数据看板正常。
- [ ] 成员管理列表、新增、编辑、删除正常。
- [ ] 分组管理列表、新增、编辑、删除正常。
- [ ] 签到任务列表正常。
- [ ] 创建签到正常。
- [ ] 签到详情正常。
- [ ] 结束签到正常。
- [ ] 退出登录正常。
- [ ] 安卓返回键正常。
- [ ] 横屏无明显 overflow。
