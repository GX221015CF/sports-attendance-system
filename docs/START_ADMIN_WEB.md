# Windows 一键启动电脑后台

本文档用于说明如何在 Windows 上启动运动队签到考勤系统的 Web 管理后台。

## 启动方式

在项目根目录中双击：

```text
启动电脑后台.bat
```

脚本会自动进入 `admin_web` 目录并启动 Vite 开发服务器。

## 第一次启动较慢

如果 `admin_web/node_modules` 不存在，脚本会先执行：

```bash
npm install
```

第一次安装依赖可能需要几分钟，属于正常情况。

## 浏览器没有自动打开

脚本会默认打开：

```text
http://localhost:5173
```

如果 5173 端口被占用，Vite 可能会使用其他端口。请查看启动窗口中的 `Local` 地址，并在浏览器中手动打开。

## 提示 npm 不是命令

说明当前电脑没有安装 Node.js，或安装后没有重新打开终端。

处理方式：

1. 安装 Node.js。
2. 安装完成后重新打开 `启动电脑后台.bat`。
3. 如果仍然失败，重启电脑后再试。

## 数据加载失败

如果页面能打开，但数据加载失败，请检查：

```text
admin_web/.env
```

确认其中已经填写：

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

不要把 `.env` 文件或其中的真实 key 发给别人，也不要提交到 Git。

## 关闭后台

关闭启动窗口，或在窗口中按 `Ctrl + C` 后确认，即可停止本地后台服务。
