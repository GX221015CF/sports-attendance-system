# 展示素材来源与许可状态

本仓库用于队齐项目和个人作品展示。公开可访问性与开源许可证各自管理，当前仓库未配置统一的开源许可证。第三方依赖和素材的权利归属按各自来源处理。

## 第一版视频与代表截图

- `demo.mp4` 为项目所有者选定的 Remotion 第一版完整初剪 full-v1，原文件名为 `duiqi-full-intro-first-cut-v1.mp4`。
- 视频来源为队齐 App、Web 管理后台与 Excel 操作录屏，经原制作流程映射为演示身份并整理为介绍片。
- `images/` 的封面、成员、创建、签到、备注、Web 与 Excel 图像均从同一视频提取，时间点和指纹记录在 [媒体清单](media-manifest.json)。
- 视频展示本项目功能，沿用现有字幕、操作、状态和声音。源工程、录屏和含映射原值的制作清单由作者本地保管。

## 品牌与设计

- “队齐”名称及当前图标由项目候选方案中选定，项目品牌资源见 [品牌目录](../../design/branding/20261025/)。
- App 运行时品牌 PNG 见 [duiqi.png](../../mobile_app/assets/branding/duiqi.png)。
- `design/stitch-ui/` 为初期界面参考，属于历史设计资料。当前视频和展示截图使用 full-v1 的画面。

## 声音

运行时共六个 WAV，映射与生成说明见 [交互音效](../INTERACTION_AUDIO.md)。

| 素材 | 来源与状态 |
| --- | --- |
| `ui_tap.wav`、`ui_select.wav`、`ui_success.wav`、`ui_failure.wav`、`ui_transition.wav` | 使用 Python 标准库生成的五种项目通用声音 |
| `ui_checkin_success.wav` | 用户为本项目选定的 deep + select 参考组合，来源研究对象为鲨鱼记账，使用经过现有项目验收 |
| full-v1 音轨 | 对应操作选区的录屏声音，原制作流程做片段增益和切口淡变 |

第三方参考组合的独立再分发和商用授权证明当前未随仓库提供。项目中的选择与体验验收记录说明采用过程，第三方原素材的权利仍归其权利人。后续如需扩大素材使用范围，应核对来源许可或采用具有明确授权的替代素材。

研究方法与来源记录见 [声音研究说明](../SHARK_AUDIO_RESEARCH.md)。

## 软件与工具

Flutter、React、Vite、Ant Design、Supabase、SQLite 和相关依赖遵循其各自许可证。依赖版本可从包清单和锁文件核对。

视频使用 Remotion 制作，工具署名保留在成片结尾。Remotion 工具的使用许可与本项目代码、图像及音效的权利范围分别适用。

## 记录范围

本页记录当前材料的来源、处理方式和已知许可状态。后续明确开源许可或替换素材时，可在相应提交中更新来源与适用范围。
